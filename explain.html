4.2 Helpers + Phone Lock

  • isDevEmail(e): checks if email equals DEV_EMAIL
  • setMsg(t,c): shows text under login
  • setBusy(): disables button, shows Please wait...
  • togglePass(): SHOW / HIDE password
  • show(id): hides all screens, shows one, closes drawer
  • phoneLockEnabled(): checks localStorage salaama_phone_lock = 1
  • setupPhoneLock(): uses WebAuthn - Fingerprint / Face / PIN. Saves webauthn_id
  • unlockWithPhoneLock(): asks fingerprint, then if auth.currentUser exists, goes to handleAfterAuth

4.3 ensureCollections + ensureUserDoc

ensureCollections(): For each of 9 collections, if empty, creates doc _init. So collections always exist. _init docs are ignored in counts.

ensureUserDoc(): If user doc does not exist, creates it. If isDev, roles = DEV_ROLES, approved = true, status approved. If normal user, roles = [], approved = false, status pending. If isDev but doc says not developer, it updates to developer + all roles.

4.4 handleAfterAuth + Login / Signup

handleAfterAuth(email):

  1. Sets currentUid, calls ensureCollections, saves email in localStorage
  2. Calls ensureUserDoc
  3. If Remember checked, enablePhoneLock + setupPhoneLock
  4. If isDeveloper: approvedRoles = DEV_ROLES, show Role List
  5. Else if not approved: show Wait screen
  6. Else: approvedRoles = approvedRoles, show Role List

firebaseSignup(): Checks name, email, pass 6+, creates account, if email already exists, tries login. firebaseLogin(): Signs in, if already signed in with same email, goes direct. forgotPassword(): Sends reset link. checkApproval(): Reloads user doc, if approved, shows Role List.

5.1 ROLES + getDash()

ROLES array has 10 objects: id, name, icon, desc, func. Example:

{id:'admin', name:'Admin', icon:'👑', func:'Approve users • Staff • Students • Finance'}

getDash(): Returns tiles by cur. Admin 9 tiles, Bursar 6, Headteacher 6, DOS 5, Teacher 6, Tahfiizu 5, Other 2, Parent 7. Drawer and Dashboard both use getDash().

5.2 renderRoleList + toggleRoleCard

renderRoleList(): Loops ROLES, creates roleCard. If approved = green + APPROVED badge, if selected but not approved = orange + PENDING, else grey + Tap to Select.

toggleRoleCard(id): RULE - If GREEN approved, tapping ENTERS dashboard: cur=id, switchRole, show dash, loadDashboard. If not approved, it only selects / deselects. Max: Normal 3 roles, Admin 4, Developer 10.

confirmRoles(): Enters first approved selected role. switchRole(r): Only called from Role List, sets cur, updates topbar, builds tiles.

5.3 loadDashboard()

Most important function:

realStudents = count students without _init
collected = sum fees.amount
realPresent = count attendance today
isFinance = ['admin','bursar'].includes(cur)
isTeacherLike = ['teacher_sec','teacher_theo','tahfiizu','other']

Live Data box: If isTeacherLike, hide it. Else show it.

Stats:

  • Parent: My Children + My Balance + Present
  • isFinance (Admin/Bursar): Students + Collected + Present
  • Others: Students + Present ONLY - No Collected

Then calls loadLiveStudents().

5.4 loadLiveStudents()

Shows Live Data box:

  • Teacher / Tahfiizu / Other: returns empty, nothing shown
  • Parent: only students where parentId == currentUid
  • Else: first 20 students
  • Admin / Bursar / Parent: Name - Class - Fees - Paid - Balance
  • DOS / Headteacher: Name - Class ONLY, no fees

If not firebaseReady, shows Not Connected. If empty, No students yet.

6.2 Save Functions

  • saveStudent(): adds to students: name, cls, parentName, fees, paid, parentId=currentUid
  • saveStaff(): adds to staff: name, role, salary
  • fillStudentSelect(): fills dropdown with Name - Class - Bal. For fees, onchange shows Fees / Paid / Balance
  • saveFee(): must SELECT student, must amount >0. Adds to fees, then updates student paid = oldPaid + amount. Then listFees + loadDashboard
  • saveAttendance(): must SELECT student. Adds to attendance with date = today, by=userName
  • saveResult(): eng+math+sci = total, saves to results
  • saveNotice(), saveTahfiizu(): save to notices / tahfiizu

6.3 List Functions + Approval

  • listStudents, listStaff, listFees, listAttendance, listResults, listNotices, listMyChildren, listClasses, listTahfiizu: each reads collection, skips _init, builds cards in listBox
  • loadPendingUsers(): users where approved==false, skips developer email, shows Approve / Reject buttons
  • approveUser(): if roles includes admin, finalRoles = SCHOOL_ADMIN_ROLES (4 roles), else roles as requested. Sets approved true
  • rejectUser(): approved false, approvedRoles [], status rejected
  • makeSchoolAdmin(): finds by email, sets approved + 4 roles + isSchoolAdmin true
  • listAllUsers(): shows all users + DEVELOPER / SCHOOL ADMIN / User label
  • saveRolesToFirebase(): Developer saves directly approved, normal user saves pending and goes to Wait

6.4 Salaama AI + Install

askAI(): Reads question lowercased, checks keywords:

  • how many / students → count students
  • balance → find student by name, show Fees - Paid - Balance
  • attendance → count today + list
  • top / result → highest total /300
  • fees / collected → sum fees
  • notice → latest notice
  • tahfiizu / quran → last 3 presentations
  • my child → students where parentId == currentUid

installApp(): Uses beforeinstallprompt. If no prompt, alert Chrome > 3 dots > Add to Home screen. Bottom timer: After 4.6 sec, hide splash, if phoneLockEnabled show Unlock, else show Login.
